# Code of Conduct

## objective

I want this repository to be a welcoming place for learning *C++*. Anyone who participates—whether by submitting a pull request, opening an issue, or leaving a comment—is expected to follow these rules:

## Expected Behavior

- Treat everyone with respect and courtesy
- Keep discussions relevant to the project and to learning C++
- When proposing a change, clearly explain what is changing and why
- Accept constructive feedback and offer your own criticism respectfully
- Remember that people have different levels of experience.

## Unacceptable Behavior

- Insults, harassment, or threats
- Racist or discriminatory language or content
- Trolling, repeated provocations, or deliberately offensive comments
- Political or religious content
- Pull requests or comments unrelated to the project that hinder discussions

## Reporting

If you notice a violation of these rules, or if you receive offensive content, please email me at **argenti.projects@gmail.com**. I will review the report and try to address it as soon as possible

Thank you all for helping to keep this project respectful and useful for those who are learning
